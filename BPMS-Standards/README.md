## قواعد انتشار
- هر سند: عنوان، مالک، دامنه، نسخه، وضعیت و تاریخچه تغییرات داشته باشد.
- داده‌های حساس مشتری و دسترسی‌های داخلی منتشر نشوند.
- راهکار آزموده‌شده از فرضیه و نمونه آموزشی تفکیک شود.
- بازبینی فنی و تأیید مسئول مربوطه پیش از معرفی سند به‌عنوان استاندارد الزامی است.
- این مسیر مکمل بخش‌های فنی فعلی مخزن است، نه جایگزین آنها.
