# OFM-FB-002 — جستجوی مقادیر فیلدها

**وضعیت:** آزمایش‌شده و تأییدشده توسط کاربر

## هدف
دریافت نام لاتین فرم از `Latintitleform`، انتخاب نام فیلد از `Fieldtitle`، فیلتر اختیاری `Searchfilter` و ثبت نتیجه در `DG0`.

## پیش‌نیاز
گرید `DG1` حاوی `Propertynameee`، گرید مقصد `DG0`، فیلد `textareaField1` و تابع `FonixUtils.getInternalResourceData`.

## خروجی DG0
`Propertynameee0`، `valueee0`، `Sn0` و `FormVersion0`.

## رفتار فیلتر
- فیلتر خالی: همه رکوردهای **دریافت‌شده** نمایش داده می‌شوند، حتی اگر فیلد انتخابی وجود نداشته باشد.
- فیلتر غیرخالی: جستجوی بخشی از متن بدون حساسیت به حروف کوچک/بزرگ.
- مقدار `valueee` در DG1 استفاده نمی‌شود.

## محدودیت
حداکثر ۱۰۰ رکورد درخواست می‌شود؛ پوشش کامل داده‌های بیش از این تعداد تأیید نشده است. خواندن مقدار از `record.data[fieldName]` در سطح مستقیم انجام می‌شود.
