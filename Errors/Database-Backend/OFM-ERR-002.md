# OFM-ERR-002 — Character literal must contain exactly one character

- تاریخ مشاهده: ۲۰۲۶-۱۱-۰۳
- دسته: Database-Backend / .NET
- وضعیت: راهنمای عمومی ثبت شده؛ منشأ دقیق در فرم نیازمند بررسی است

## پیام خطا
`Character literal must contain exactly one character`

## توضیح فنی
در زبان C#، literal با کوتیشن تکی برای یک کاراکتر است، مانند `'A'`. نوشتن چند کاراکتر مانند `'AB'` معتبر نیست. رشته چندکاراکتری باید با کوتیشن دوتایی نوشته شود: `"AB"`.

## بررسی و رفع
کد یا عبارت تولیدکننده خطا را پیدا کنید؛ موارد استفاده از کوتیشن تکی برای رشته‌های چندکاراکتری را بررسی و در صورت تطابق با نحو C# اصلاح کنید. در محیط فرم‌ساز ممکن است خطا از کد تولیدشده یا سمت سرور باشد؛ بدون مشاهده قطعه کد نمی‌توان محل دقیق را تأیید کرد.

## پاسخ پیشنهادی پشتیبانی
با سلام و احترام، این خطا نشان می‌دهد در یکی از عبارت‌های پردازش‌شده، مقدار چندکاراکتری به شکل literal تک‌کاراکتری تعریف شده است. لطفاً عبارت یا کد مرتبط بررسی شود؛ در C# برای رشته‌های چندکاراکتری باید از کوتیشن دوتایی استفاده شود.
