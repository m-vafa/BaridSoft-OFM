# آرشیو خطاهای فرم‌ساز برید سامانه

این بخش برای ثبت خطاهای OFM / Fonix / BPMS، علل محتمل، مراحل عیب‌یابی و پاسخ پشتیبانی ایجاد شده است.

> هشدار: این مخزن عمومی است. اطلاعات مشتری، توکن‌ها، آدرس‌های داخلی، شناسه‌های شخصی و تصاویر دارای اطلاعات حساس را منتشر نکنید.

## دسته‌بندی‌ها
- Form-Designer: طراحی فرم و کامپوننت‌ها
- Workflow-BPMS: گردش کار، یال‌ها و دلایل وضعیت
- DataGrid: داده‌ها و ساختار گرید
- Fonix-JavaScript: اسکریپت‌ها و رویدادها
- API-Integration: وب‌سرویس‌ها و یکپارچه‌سازی
- Database-Backend: خطاهای سرور، .NET و داده‌ها
