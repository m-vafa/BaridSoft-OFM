# BaridSoft-OFM

پایگاه دانش فنی و آموزشی فرم‌ساز برید سامانه (OFM / Fonix / BPMS).

## هدف
نگهداری کدهای آزمایش‌شده، مستندات فنی، گزارش تست‌ها، خطاهای شناخته‌شده و محتوای آموزشی با تاریخچه نسخه‌ها.

## کدهای پایه تأییدشده

| شناسه | عنوان | وضعیت |
|---|---|---|
| [OFM-FB-001](02-Fonix-Buttons/OFM-FB-001-Schema-Extractor/) | استخراج Schema فرم مقصد و تکمیل DG1 | تأییدشده در آزمایش کاربر |
| [OFM-FB-002](02-Fonix-Buttons/OFM-FB-002-Field-Search/) | جستجوی مقادیر فیلدها و تکمیل DG0 | تأییدشده در آزمایش کاربر |

## ساختار
- `01-Components/`: کامپوننت‌ها و تنظیمات
- `02-Fonix-Buttons/`: کتابخانه کدها
- `03-APIs-Resources/`: API و منابع داده
- `04-BPMS-Workflows/`: گردش کار
- `05-MRT-Reports/`: قالب‌های چاپ
- `06-Error-KnowledgeBase/`: خطاها و راهکارها
- `07-Real-Scenarios/`: سناریوهای واقعی
- `08-Customer-Training/`: آموزش مشتریان
- `09-Test-History/`: گزارش آزمایش‌ها

## سیاست نسخه‌بندی
فایل `code.js` هر نمونه در نسخه پایه بدون بازنویسی نگهداری می‌شود. تغییرات بعدی ابتدا در شاخه جداگانه آزمایش می‌شوند. وضعیت «تأییدشده» به آزمایش قبلی کاربر اشاره دارد، نه اجرای مجدد خودکار در محیط OFM.

## امنیت
مخزن عمومی است؛ اطلاعات محرمانه، داده‌های شخصی، توکن‌ها، کوکی‌ها و نشانی‌های داخلی حساس نباید در آن منتشر شوند.
